### 题目来源：LeetCode-169-多数元素

题目描述：  
给定一个大小为 n 的数组 nums ，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。  
你可以假设数组是非空的，并且给定的数组总是存在多数元素。  

题目思路：

> 摩尔投票法（Boyer-Moore）：维护一个候选元素 `candidate` 与计数器 `count`。  
> 遍历数组：若 `count == 0` 则将当前元素设为 `candidate`；若当前元素等于 `candidate` 则 `count++`，否则 `count--`。  
> 由于多数元素出现次数严格大于一半，相互抵消后最终留下的 `candidate` 必为多数元素，时间复杂度 O(n)、空间 O(1)。  

题目代码：

```cpp
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int candidate = 0, count = 0;
        for (int num : nums) {
            if (count == 0) candidate = num;
            count += (num == candidate) ? 1 : -1;
        }
        return candidate;
    }
};
```

### 题目来源：LeetCode-75-颜色分类

题目描述：  
给定一个包含红色、白色和蓝色、共 n 个元素的数组 nums ，**原地**对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。  
我们使用整数 `0`、`1` 和 `2` 分别表示红色、白色和蓝色。  
必须在不使用库内置的 `sort` 函数的情况下解决这个问题。  

题目思路：

> 荷兰国旗问题（三指针）：`p0` 指向已排好的 0 的右边界，`p2` 指向已排好的 2 的左边界，`cur` 从头遍历。  
> - `nums[cur] == 0`：交换 `cur` 与 `p0`，`cur++`、`p0++`；  
> - `nums[cur] == 2`：交换 `cur` 与 `p2`，`p2--`（`cur` 不动，换过来的元素还需再判）；  
> - `nums[cur] == 1`：`cur++`。  
> 当 `cur > p2` 时结束，时间复杂度 O(n)、空间 O(1)。  

题目代码：

```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int p0 = 0, p2 = (int)nums.size() - 1, cur = 0;
        while (cur <= p2) {
            if (nums[cur] == 0) {
                swap(nums[cur], nums[p0]);
                cur++; p0++;
            } else if (nums[cur] == 2) {
                swap(nums[cur], nums[p2]);
                p2--;
            } else {
                cur++;
            }
        }
    }
};
```
