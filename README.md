# 完整题单 · 算法刷题分类整理

> 将刷过的题目按专题进行分类整理，每个专题一个文件夹，内含题解 Markdown 与题目截图。

---

## 目录结构

```
.
├── README.md
├── 完整题单00、日期、时间/
│   ├── 日期、时间.md
│   └── images/
├── 完整题单00、紫皮书/
│   ├── 紫皮书.md
│   └── images/
├── 完整题单01、双指针/
├── 完整题单01、滑动窗口/
├── ...
├── 完整题单12、字符串(条件判断)/
└── 完整题单13、技巧/
```

- 每个专题一个文件夹，文件夹名 = `完整题单<编号>、<专题名>`
- 每篇题解为一个 `.md` 文件，文件名与专题名一致
- 题目截图统一存放在该专题下的 `images/` 目录

## 使用说明

- 每篇 `.md` 头部包含元信息：原文链接、发布时间、阅读量、CSDN 文章 ID，可回溯到原始博文
- 题单内的图片引用为相对路径 `images/xxx.png`，配合所在文件夹的 `images/` 目录使用
- 题单按「No.0 筑基 → No.1 基础 → No.2 进阶 → No.3 思维扩展」的梯度组织
